# Projects guide

## Overview

Open **Projects**, next to **Issues**, to browse the selected initiative's projects and manage milestones.

## Before you start

Sign in under **Settings > Account**. Projects uses the same API account and initiative selection as Issues.

## Main view

Select a project in the navigator. **Overview** shows its status, health, priority, lead, dates, description, timeline and latest update.

## Toolbar and filters

Use the initiative switcher to change the project list. The chosen initiative applies across Spaces. Select **Milestones** to see the project's milestones.

## Details

The milestone list shows target dates, status and progress from linked issues where the API provides it.

## Actions

Use **New milestone** to add a milestone. Each milestone offers editing, moving and deleting. **Mark as done** completes it manually. **Reopen** is available for a manually completed milestone whose issues do not still complete it.

## Keyboard shortcuts

Use the app's Reload command to refresh Projects and Escape to dismiss a milestone dialog.

## Settings

Projects is available in builds with an API backend.

## Troubleshooting

If the milestone changed while you were editing, keep a copy of your draft, cancel the dialog and reload the project before editing again.

## Limits

Project properties and updates are read-only here. Archived projects' milestones are read-only.
