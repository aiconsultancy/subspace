# Projects guide

## Overview

Open **Projects**, next to **Issues**, to browse the selected initiative's projects and manage milestones.

## Before you start

Sign in under **Settings > Account**. Projects uses the same API account and initiative selection as Issues.

## Main view

Select a project in the navigator. **Overview** shows its status, health, priority, lead, dates, description, timeline and latest update.

The initiative, **Overview**, **Milestones** and **Back** stay on one line at the top of the pane. In a narrow window, the last of them move into the menu at the end of that line.

Hover over a milestone on the timeline to see a preview of its linked issues and their statuses. Select a milestone to open its details.

## Toolbar and filters

Use the initiative switcher to change the project list. The chosen initiative applies across Spaces. Select **Milestones** to see the project's milestones.

## Details

The milestone list shows target dates, status and progress from linked issues. Select a milestone to read its description and see all its linked issues and their statuses. Open an issue to work on it in Issues. **Back** returns to the milestone and its scroll position, and **Back** from the milestone returns to the Overview or Milestones view you came from.

## Actions

Use **New milestone** to add a milestone. Each milestone offers editing, moving and deleting. **Mark as done** completes it manually. **Reopen** is available for a manually completed milestone whose issues do not still complete it.

Use **Edit project** in Overview to change the name, description, status, priority, start date or target date. The API checks your permission and the version you opened.

## Keyboard shortcuts

Use the app's Reload command to refresh Projects and Escape to dismiss an editor.

## Settings

Projects is available in builds with an API backend.

## Troubleshooting

If a project or milestone changed while you were editing, keep a copy of your draft, cancel the dialog and reload before editing again.

## Limits

Project updates, leads and initiative assignments are read-only here. Archived projects and their milestones are read-only.
