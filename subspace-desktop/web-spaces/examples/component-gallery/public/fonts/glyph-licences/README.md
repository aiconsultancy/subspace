# JetBrainsMono Nerd Font glyph licences

The bundled font's character map was checked against the
[Nerd Fonts v3.5.1 glyph map](https://github.com/ryanoasis/nerd-fonts/blob/v3.5.1/glyphnames.json)
and [patcher](https://github.com/ryanoasis/nerd-fonts/blob/v3.5.1/font-patcher).
The [pinned glyph inventory](https://github.com/ryanoasis/nerd-fonts/blob/v3.5.1/src/glyphs/README.md)
records the upstream versions. Eight licence files below come from that
tag's `src/glyphs/` directory. The other notices come from the cited sources.

Font Logos in the pinned Nerd Fonts source is byte-identical to the 1.4.0
release font. The glyph inventory still lists 1.3.0 and describes it as
unlicensed. Brand icons remain trademarks of their owners.

The Font Awesome Extension TTF matches the 0.0.3 tag. Its repository
[added the MIT text](https://github.com/AndreLZGava/font-awesome-extension/blob/09d80249058ee8018a45da30add4339289dbb466/LICENCE)
after that tag. The legacy Devicons README declares MIT for the pre-fork
glyphs. The same repository later
[added the full text](https://github.com/vorillaz/devicons/blob/8947499eeac633315de2a76fde08fc71619dd4ba/LICENSE).
