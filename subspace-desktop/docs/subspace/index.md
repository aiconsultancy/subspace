## What is Subspace?

Subspace is the desktop app built from the Subspace Framework. It brings
GitHub pull requests and Actions, agent tasks, IRC chats and other boards
into one desktop workspace. The app is a prototype. Board availability depends on the platform,
build features and enabled boards.

Use the board switcher or command palette to open a board. Each board has its
own Help guide, connection requirements and actions. Disabling a board hides it;
it does not remove that board from the installed binary.
