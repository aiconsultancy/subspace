## Installation reference

The [shared installation guide](../installation.md) covers supported targets,
checksums, installer options, source builds and signed macOS packaging.
Subspace's binary is `subspace`; its signed macOS bundle is `Subspace.app`.

For nightly, alpha and beta builds, read the shared
[pre-release guide](../installation.md#pre-releases). Each channel has separate
app data and stays in that channel when updating.
