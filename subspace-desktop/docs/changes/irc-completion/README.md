# IRC completion: `@` mentions, `/` commands, arguments and `#` channels

The IRC composer completes the word before the cursor. `@` offers people,
`/` at the start offers commands, a command's first argument offers channels
or nicks, and `#` offers the channels you are in. The list is the shared
completion list above every chat input. The agent chat's `/` list now uses
that same list.
