# Twilight Two for new installs

A new install of the Subspace App opens in **Twilight Two**. An existing
install keeps the theme it shows, including one that never saved a theme,
which still shows **Cupertino Dark**. The app records the theme at a new
install's first desktop start, so a later change of default never moves
anyone.
