# Intent: Twilight Two for new installs

The owner asked for **Twilight Two** to be the default theme of the Subspace
App on new installs, and only on new installs.

- **New installs.** The app starting with no configuration of its own, its
  first run, opens in Twilight Two.
- **Existing installs.** An install keeps what it shows today when it
  updates, even if it never saved a theme. The owner has such an install, so
  changing the default alone is not enough: an install with no saved theme
  would follow it.
- **Light mode.** Twilight Two has only a dark variant. The owner decided
  that a new install opens in Twilight Two, dark, even when the system is in
  light mode; people can change the theme afterwards.
- **Other products.** The Framework's own default, Cupertino Dark, stays as
  it is. Twilight Two for new installs is the Subspace App's choice, stated
  in its product descriptor.
- **Command line.** Command-line and headless runs neither create nor change
  any file for this.
