# Intent: Cupertino theme

Give Subspace a native macOS look modelled on Wake's library design: silver and
warm grey in light mode, graphite and warm black in dark mode, system blue only
for primary actions, selection and focus, the system UI font, a 4 px spacing
grid, 32 px rows, rounded inset selection and quiet chrome.

A theme must be able to carry the whole look, not only colours. Sizes, radii,
row treatment and chrome materials therefore come from theme tokens, so
Cupertino Light and Cupertino Dark can change them while Subspace One Dark keeps
its appearance.
