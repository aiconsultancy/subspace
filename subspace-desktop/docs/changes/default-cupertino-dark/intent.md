# Intent: Cupertino Dark as the default theme

The owner asked: "Just give me Cupertino dark proofs and make that the
default theme please".

- **Default theme.** A new user, with no `appearance.theme` in `state.json`,
  sees Cupertino Dark. A saved choice, including Subspace One Dark, still
  wins. Subspace One Dark and Cupertino Light stay available.
- **Proofs.** Screenshot evidence is captured in Cupertino Dark. Other themes
  are captured only when a change is about a theme, colour or contrast.

Out of scope: following the system appearance. Subspace has no light/dark
switching, so there is no light pairing to choose; a user who wants a light
window selects Cupertino Light.
