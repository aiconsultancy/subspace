# Channels draft keys and reference card examples

Up and Down jump to the start and end of a Channels draft. Up in an empty
composer still recalls sent messages, and the arrows still move through
completion choices while a mention or command list is open.

The native Component gallery shows the Channels issue and pull request
surfaces with neutral outlines and state colour in the pill.
