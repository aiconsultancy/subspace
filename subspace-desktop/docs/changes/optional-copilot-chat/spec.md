# Chat engine selection

- A configuration with no engine selected opens Chat in the Off state. The
  panel explains where to select an engine, and the status bar shows Chat off.
- Settings > Chat offers Off and Copilot. Pi and ACP each require their experiment to
  be enabled. Save and restart apply the engine selection.
- A saved Copilot, Pi or ACP selection continues to select that engine.
  Disabling the selected engine's experiment changes the draft selection to Off.
- Opening Chat while Off starts no runtime and offers no composer or reconnect
  action. Saved conversations remain available on returning to their engine.
