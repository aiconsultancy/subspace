# PRs board: favourite repositories and All open

The PRs board can search GitHub and star repositories. The favourites are the
config file's `repos`, the one list that PRs, Copilot Agents, Actions and the
agent tools share. A star saves at once and applies without a restart.
**All open** lists every open pull request in the favourites, and an optional
**Favourites only** filter limits Mine, Review requested and Involved to them.
Settings shows the same list with Remove and **Add repository…**.

- [Intent](intent.md): the owner's feedback and how it was delivered.
- [Spec](spec.md): the controls, the save boundaries, the query strategy and
  live propagation.
- [Delivery](delivery.md): tests and before/after evidence.
- [Tasks](tasks.md).
