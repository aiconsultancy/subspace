# Issues list and page spacing

The full issue page and its path share the list's 24 px content inset. The
page is centred and capped at 80 rem. The Issues list uses rows and loading
skeletons that are 1.125 times the theme's row height.

Label chips wrap in the Properties panel and stop at 12 rem with an ellipsis
and a tooltip for the full label. Long values stay within the panel. Subspace
uses the NETT detail it already reads for the panel's values.

Board layout tests check the long label and property rows at 1,000 and 720 px.
The macOS before-and-after captures use the same fictional long label.
