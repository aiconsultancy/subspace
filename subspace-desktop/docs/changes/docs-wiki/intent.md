# Documentation wiki and ways of working

The owner wants agents reminded to use conventional commits, through a ways of
working document referenced from AGENTS.md. The `docs/` folder should work as
a wiki: one index page that links every other page, grouped by area with "if
you want to know about X, read Y" guidance, so an agent can read the index and
choose the pages it needs for the current session.

Release 0.2.1 contained new features and should have been 0.3.0. It stays as
published, but the rule for choosing future versions should be written down.
