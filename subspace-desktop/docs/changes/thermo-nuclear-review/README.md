# Require thermo-nuclear review

[Issue #137](https://github.com/aiconsultancy/subspace/issues/137) requires a
maintainability review before code changes reach merge. The agent instructions
define the review and the documentation-only exception. The PR template
records the checkbox, reviewed head and outcome. The ways-of-working
checklist links to the policy.

Validate that a docs-only PR can mark the outcome N/A, that adding a code
change requires a review, and that a changed head requires fresh evidence.
Run the documentation and file hygiene hooks for these Markdown changes.
