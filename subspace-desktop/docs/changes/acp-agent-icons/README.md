# ACP agent marks and names

The chat engine is now shown with its product's own mark and short name.
Codex shows the OpenAI mark, Claude Code shows the Claude mark, and OpenCode
and Gemini CLI show their own marks. The status bar reads "Codex ready",
"Claude ready" or "OpenCode ready" instead of "Codex (ACP) ready".
