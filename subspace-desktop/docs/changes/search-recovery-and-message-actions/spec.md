# Behaviour

- Issues and Decisions check for a match outside the current filters after
  a successful empty search. Recovery stays within the selected initiative
  and the signed-in account. The action keeps the search text and adjusts
  the view or filters needed to show a match.
- The reaction picker opens at the reaction button and includes **Thank
  you**. **Stop** is a separate action for eligible running requests and
  their verified agent replies. It uses the existing guarded Stargate
  reaction workflow.
- Ships, Starbase, Command and Fleet audit offer the channel, **Thread** and
  **People** tabs. With **Thread** open, clicking a message previews it.
  **Reply in thread** pins the thread and focuses its editor. **Unpin
  thread** resumes following clicks. Drafts stay with their threads.
- **Here now** in the Ship inspector shows its member avatars side by side
  so initials remain legible.
- A right-click anywhere on a message opens its native menu. The menu offers
  **Reply in thread** when available and preserves native text selection,
  copy and link actions. **Add to local model chat** appears when local Chat
  is enabled. Hover tooltips use action names. Keyboard shortcuts remain
  available from the focused transcript.
