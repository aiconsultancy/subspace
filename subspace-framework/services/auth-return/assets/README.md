# Callback artwork

These assets are embedded in the loopback OAuth callback page. It must work
offline and must not send an OAuth callback URL to an external image host.

- `subspace.svg`: the dark Subspace product mark. Keep this service-owned copy
  in sync when the mark changes; the service must not depend on an app crate.

The logo shapes and colours are unchanged. The browser template supplies its
accessible name and display size.
